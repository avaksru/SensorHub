Скрипты

Единый каталог: on_update() — по расписанию, привязывается к элементам на вкладке «Сенсоры»; on_frame(fx) — кадры светодиодов, включается кнопкой «▶ Включить» или rgb_effect('fx:имя', 0) из любого скрипта. Оба хука в одном файле работают вместе и делят общий state; правка активной анимации подхватывается сама (без перезагрузки).

Справочник
on_update() — вызывается по poll_interval; верните {ключ=число} — это станет показаниями элемента
sensors[id] — данные любых элементов по ID со страницы «Сенсоры» (sensors.temp_room.temperature)
virtual_get(id) — значение виртуального элемента по ID (страница «Сенсоры»): поле ввода (INPUT) — число, если введено число, иначе строка (текст); виртуальный переключатель (SWITCH) — 1/0 · virtual_set(id, знач) — записать значение (сохраняется в памяти устройства)
read(id) — синоним sensors[id] · self.id — ID этого элемента · self.script — файл
state — таблица, живущая между вызовами · tick — счётчик запусков
log(...), print(...) — журнал (виден по кнопке «Тест»)
mqtt_publish(topic,payload) · mqtt_connected()
time() — unix-секунды · time_ms() — мс с загрузки · sync_time([host]) — SNTP (без host — сервер из настроек «Подключение»; авто-старт при получении IP) · date_str(fmt) — локальное время (часовой пояс задаётся на вкладке «Подключение»)
json_encode(t) · json_decode(s)
gpio_mode(pin,mode): 'in'|'in_pu'|'in_pd'|'out' · gpio_read(pin) · gpio_write(pin,0|1)
pwm_setup(pin,freq) · pwm_set(pin,duty%) — LEDC (до 6 каналов)
rgb_setup{mode='pwm', r=,g=,b=, invert=} или {mode='ws2812', pin=, count=} · матрица: cols=, rows=, layout='snake'|'rows'|'snake_col'|'cols', flipx=, flipy= · gamma=
rgb_set(r,g,b) · rgb_set_led(i,r,g,b) · rgb_brightness(0..100) · rgb_hsv(h,s,v) · rgb_hex('#ff8800')
rgb_effect('blink'|'breathe'|'rainbow'|'chase'|'none'|'fadein'|'fadeout', ms) — fade: плавное вкл/выкл за ms · 'fx:имя' — анимация из Lua-файла с on_frame (правится без перепрошивки) · rgb_power(0|1) · rgb_state()
adc_read(pin) — 0..4095 (на ESP32-C6: GPIO0–6)
sleep_ms(ms) — ≤1000, пауза тормозит все скрипты (и кадры анимации)
Гибрид — on_update() и on_frame(fx) в одном файле делят общий state/local; rgb_setup{...} удобно задать на первом кадре (fx.frame == 1)
on_update() выполняется не дольше 250 мс (watchdog), on_frame() — ~30 мс. Ошибка не роняет систему — показывается в списке и в «Тесте».
on_frame(fx) — вызывается на каждом кадре движения (10–30 Гц; бюджет ~30 мс)
fx.t — мс от старта эффекта · fx.frame — номер кадра · fx.cols/rows/count
fx.px(x,y,r,g,b) · fx.set(i,r,g,b) · fx.px_hsv(x,y,h,s,v) · fx.set_hsv(i,h,s,v) · fx.clear(r,g,b)
fx.noise2(x, y, t) — value-noise 0..255 из C (быстрый; слои шумов = плавные эффекты)
fx.setpal{'#000', {255,80,0}, ...} · fx.pxg(x,y,t01) · r,g,b = fx.grad(t01) — палитра до 8 стопов
fx.heat(i) / fx.heat_set(i,v) — персистентный буфер (симуляции пламени)
Ошибка в кадре отключает эффект (в serial-логе видно); при исправлении файла он перезагрузится сам.
